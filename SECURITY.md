# Security Policy

## Supported Versions

We actively provide security updates for the following versions of Krasola:

| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| 1.3.x   | :white_check_mark: |
| < 1.3.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within Krasola, please follow responsible disclosure guidelines:

1. **Do NOT file a public issue or discussion.**
2. Send an email to **krasola@ambrisoft.com** (or contact the repository maintainers privately).
3. Include detailed reproduction steps, browser version, and proof-of-concept payloads where applicable.

We will acknowledge receipt within **48 hours** and provide an estimated timeline for remediation.
